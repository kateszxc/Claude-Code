6-digit stopwatch: build layout

MM:SS:CS · 3 × CD4518 counters, 6 × CD4511 drivers, NE555 clock at 100 Hz · 4 breadboards (830 points, 63 columns) · the notch of every IC points left, so pin 1 is bottom-left.

Before wiring: read the part number printed on every chip. Both of your 74HC listings are multi-variant listings. A 74HC73 is not a drop-in for the 74HC74, because its pinout is different. A 74HCT part works fine. The column numbers below are a suggested placement, not a rule.

1. How it behaves (corrected spec)

One 74HC74 flip-flop has only two states, RUN and STOP. Q drives the green LED and /Q drives the red LED, so exactly one LED is always lit. The original spec said “all LEDs off” after power-on and reset, which this hardware can’t do. Use this version in your write-up:

EventInputDisplayLEDs
Power onButton A = the power bank’s own switch00:00:00 (power-on reset, about 0.1 s)Red on, green off: “stopped at zero”
StartButton BCounts up 00:00:01 → … → 59:59:99, then wraps to 00:00:00Green on, red off
StopButton BFreezes at the current timeRed on, green off
ResumeButton BContinues from the frozen timeGreen on, red off
Reset (any time)Button C00:00:00 immediatelyRed on, green off; press B to start again

Pressing B on a clock edge can add or drop one count (10 ms), which is acceptable. Real centisecond accuracy depends on trimming the 555 (section 8). An untrimmed clock can be off by about 20%.

Why 4 boards and not 3: 6 displays, 14 ICs and 42 segment resistors need about 200 breadboard columns. Three 830-point boards have 189. Squeezing everything onto three boards leaves no room to route wires, so buy a fourth board.

3. Boards

Board 1 is the display panel: six displays side by side reading MM:SS:CS, plus the three CD4518 counters. Boards 2 and 3 hold the six CD4511 drivers and their 330 Ω resistors, 3 digits each. Board 4 is control and carries the USB power breakout. Link every board’s rails with long jumpers, and join each board’s top and bottom rails (+ to +, − to −).

Red line = +5 V rail, blue line = GND rail. Rows a–e are the lower half and f–j the upper half. Chips straddle the center gap (rows e/f) with the notch on the left, so the top row counts down from the highest pin. Pin labels: =6 = tie to pin 6 of the same chip, 08.4 = 74HC08 pin 4, #1.14 = CD4518 #1 pin 14, nc = leave empty. Green = resistors only. Each bank of seven 330 Ω resistors stands across the center gap and connects only to its own wires (no GND, no +5 V). Put a 0.1 µF ceramic right across the VCC and GND pins of every IC.

Each segment runs CD4511 output → 330 Ω (on Board 2 or 3) → jumper to the display pin on Board 1. Pins 3 and 8 are joined inside the display, so one of them to GND is enough. The two pin rows are about 15.24 mm (0.6″) apart, twice a chip’s width, so the display can’t sit in rows e/f. Put its pins in rows d and h, then wire into rows a–b and i–j, which the body doesn’t cover. Measure yours first. Before wiring, test each display: COM to GND, then touch each segment pin to +5 V through a 330 Ω resistor.

Q0, Q1, Q2, Q3 = weights 1, 2, 4, 8 (datasheets print them Q1–Q4). Pin 9 is CLOCK B and pin 10 is ENABLE B. A counter steps on a rising edge of CLOCK while ENABLE is high, or on a falling edge of ENABLE while CLOCK is low. The cascade uses the second mode: CLOCK is tied low, and the previous digit’s Q3 falls on 9→0 (Q2 falls on 6→0 for ÷6), which steps the next digit. CLOCK and ENABLE are not interchangeable in this wiring, because a swapped pair never counts. RESET is active-HIGH. The ÷6 stages count to 6 (0110), then Q1·Q2 resets them to 0 right away, so the 6 never shows.

8. Control board extras

  • Button B (start/stop): 100 kΩ from +5 V to the node, 0.1 µF from the node to GND, button from the node to GND, node → 74HC14 pin 3. If one press toggles twice, swap the 0.1 µF for a spare 1 µF (+ to the node, − to GND).
  • Reset (Button C): 1 µF (+ to +5 V, − to RST_NODE), 100 kΩ from RST_NODE to GND, Button C from RST_NODE to +5 V, RST_NODE → 74HC14 pin 5. At power-up the cap holds RST_NODE high for about 0.1 s, which clears the counters and the flip-flop.
  • Button legs: a 4-leg tactile button straddling the gap has its legs across the gap joined internally. The switch connects the left column to the right column, so wire one signal to the left column and the other to the right. If unsure, use two diagonally opposite legs.
  • LEDs: 74HC74 pin 5 → 330 Ω → green LED → GND. Pin 6 → 330 Ω → red LED → GND. The long leg is the + side.
  • 555 output: NE555 HIGH is only about 3.3 V, below a 74HC’s 3.5 V threshold. The 1 kΩ pull-up and the 74HC14 Schmitt input fix that.
  • 555 timing: R1 = 1 kΩ, R2 = 4.7 kΩ + 5 kΩ trimpot, C = 1 µF. f = 1.44 / ((R1 + 2·R2)·C). Target R1 + 2·R2 = 14.4 kΩ, so start with the trimpot near 2 kΩ. The range is about 70–138 Hz, which covers the cap’s ±20% tolerance.
  • Calibrating: start the stopwatch and a phone stopwatch together, then stop both at exactly 5:00 on the phone. A reading that’s too high means the clock is fast, so turn the trimpot to add resistance. A reading that’s too low means it’s slow, so turn it the other way. Each 1% (3 s per 5 min) is about 72 Ω of trimpot. Repeat until it stays within 0.1 s.

9. Bring-up order

  1. Power and rails on all 4 boards. Check 5 V on every rail with a meter.
  2. Test all 6 displays (section 5).
  3. Test the 555 alone: put an LED on its output and a bigger cap in place of the 1 µF so you can see it blink, then put the 1 µF back.
  4. Build Board 4 fully. Button B should toggle red/green, and Button C should force red.
  5. Build one digit (CD4518 #1 A + its CD4511 + resistors + display) and confirm it counts 0–9. Only then build the other five.
  6. Calibrate (section 8).
